**新功能**
- 手机上的 TwinFile 文件管理器可以借用 SyncBoard 的连接：直接浏览、管理已连接电脑上的文件，不用再配对一次；也能借 SyncBoard 手机服务访问 Android/data。第一次使用时会在 SyncBoard 里弹窗确认，之后可以在手机端 设置 → 已授权的应用 里撤销
- 电脑上只连接了 TwinFile（手机没装 SyncBoard App）时，发送文件、文件管理和手机控制会显示为灰色，并说明需要安装 SyncBoard App

**修复**
- 装在 Program Files 等需要管理员权限的文件夹时，应用内更新提示「无法替换程序文件：拒绝访问」。现在会弹出 Windows 的管理员确认，允许后自动替换并重新打开
  - 注意：这个修复从 0.4.1 开始生效。正在用 0.4.0 的话，请这一次手动下载 0.4.1 覆盖安装

**校验**：下载后可以用 SHA256SUMS.txt 核对安装包的哈希值。
