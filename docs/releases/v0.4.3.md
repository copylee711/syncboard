**新功能**
- 单向剪贴板：电脑端设置里新增「电脑剪贴板同步到手机」。关掉后，手机复制的内容照常进电脑剪贴板，电脑上复制的不再发到手机。
- 文件管理支持系统原生复制：复制的文件（包括手机上的文件）会放进 Windows 剪贴板，可以直接粘贴到桌面、资源管理器、ChatGPT、微信等。在资源管理器里复制的文件，也能在文件管理里按 Ctrl+V 粘贴进来。
- 文件管理支持拖出窗口：把文件拖出窗口就能放到桌面或其他应用里。手机上的文件会先自动取到电脑上（手机上的文件夹和超过 300 MB 的文件请用「发送到电脑」）。
- 分享菜单里的「发送到电脑」不再弹窗，发送进度显示在通知栏，发完提示一次。

**修复**
- 修复手机重启后、首次解锁前启动手机服务，解锁后会把相册里的历史图片一张接一张复制到剪贴板的问题（#2）。现在只处理两分钟内新出现的图片，关掉自动复制开关后马上停止；一次出现多张新图时只复制最后一张；暂停同步或关闭图片同步时，新截图不再发到电脑。
- 配对后自动关闭调试时会检查结果。系统不允许关闭时（如 HyperOS），手机和电脑都会提示请手动关闭（#1）。

**关于关闭调试后让手机服务常驻（#1）**
- 在 Android 16 上，通过 adb 启动的进程无法脱离 adbd 的进程组，adbd 一停止（关闭 USB/无线调试，或网络切换导致 adbd 重启），手机服务就会随之结束。vivo/iQOO 关闭开发者选项时不会停止 adbd，所以服务能保住；HyperOS 等系统会停止 adbd，暂时没有办法。

**更新提示**
- 手机端和电脑端请都更新到 0.4.3。手机端更新后，手机服务会自动换成新版本。

**校验**：下载后可以用 SHA256SUMS.txt 核对安装包的哈希值。
