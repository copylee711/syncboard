## 新增
- **允许已配对设备浏览这台电脑的文件**（电脑端设置 →「电脑」，默认关闭）：配合 [TwinFile](https://github.com/copylee711/twinfile) 文件管理器使用。打开后，配对过的 TwinFile 可以在手机上的双栏里直接浏览这台电脑的磁盘和桌面、下载等文件夹，在手机和电脑之间复制、移动，也可以改名、删除电脑上的文件（删除进回收站），图片和视频会显示缩略图。关闭时电脑拒绝所有这类请求。
- TwinFile 在设备列表里显示为「TwinFile」。它不参与剪贴板同步，也不会出现在手机控制面板和文件管理窗口里，电脑端不会尝试用 adb 启动它。

## 安全
- 只允许访问本机磁盘上的绝对路径，拒绝网络共享路径（`\server\...`）、设备路径和 `..`。
- 拒绝删除整个磁盘，删除的文件进 Windows 回收站。
- 传输和原有功能一样全程加密，每个文件都做 SHA-256 校验。

协议说明见 `docs/protocol.md` §8.1。
