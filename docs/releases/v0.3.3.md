## 新增
- **短信验证码同步到电脑**（默认开启）：手机收到验证码短信，约 1 秒内验证码就进了电脑剪贴板，并弹出 Windows 通知，直接 Ctrl+V。只发送验证码，不发送短信内容。
- **新短信在电脑上提醒**（可选，默认关闭）：整条短信用 Windows 通知显示。
- **手机通知同步**（可选，默认关闭）：微信、QQ 等 App 的新通知用 Windows 原生通知显示；5G 消息里的验证码也能同步。
  - 电脑上已经开着微信、QQ（以及 TIM、企业微信、钉钉、飞书、Telegram）时，自动跳过这些 App 的手机通知，不会弹两次。
  - 可以在电脑端设置「按 App 设置」里单独关闭某个 App 的通知。
  - 开启后手机上会多一个约 11 MB 的通知接收进程；vivo 等系统把它清理掉后，手机服务会在 1 分钟内自动把它恢复，不需要手动开「自启动」。
- 电脑端设置里新增「发送测试通知」。

## 修复
- 电脑写剪贴板时如果剪贴板正被其他程序占用，会多等一会儿再写，避免偶尔 Ctrl+V 粘贴不出来。
- 修复手机服务在某些情况下会意外退出的问题。

## 说明
- 为了让 Windows 显示通知，电脑端第一次弹通知时会在开始菜单创建一个 SyncBoard 快捷方式（新版 Windows 11 只显示有快捷方式的程序的通知）。第一条通知可能稍有延迟。
